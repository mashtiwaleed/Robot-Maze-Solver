# Robot Maze Solver

A Python GUI application that solves a maze using the Breadth-First Search (BFS) algorithm and visualizes the shortest path with robot animation.

## Features

- Maze visualization using Tkinter
- Breadth-First Search (BFS) pathfinding
- Animated robot movement
- Visual shortest path display
- Reset button to restart the maze

## Technologies Used

- Python
- Tkinter
- BFS Algorithm

## How It Works

1. The robot starts from the green cell.
2. BFS searches for the shortest path to the red goal cell.
3. The discovered path is highlighted in blue.
4. The robot follows the path step by step.
5. The Reset button returns the maze to its initial state.
